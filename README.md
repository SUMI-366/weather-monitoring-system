# Weather Monitoring System

A web-based weather monitoring system that provides weather information for selected cities using the OpenWeather API.

## Features

- City search and suggestions
- Current temperature
- Humidity
- Wind speed
- Climate/weather condition
- MongoDB weather data storage
- Latest weather report retrieval
- Weather history and analytics

## Technology Stack

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Python
- Flask / FastAPI

### Database
- MongoDB

### External API
- OpenWeather API

## Architecture

Frontend → Python Backend → MongoDB  
                     ↘ OpenWeather API
